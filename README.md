# 同窗 · 复旦学生家教匹配体验版

这是策划书对应的手机优先交互原型。它用同一套代码生成浏览器版和微信小程序版，所有人物、认证、联系方式和付款均为模拟数据，不会提交真实需求或扣款。

## 已完成

- 家长可多选数学、英语、语文、物理、化学、生物、政治、历史、地理，再填写年级、授课方式、预算、位置和多个固定课次。
- 按学段、全部所选科目、时间、价格、性别偏好和通勤规则推荐 3–5 名学生。
- 同一学生覆盖全部课次优先；推荐结果解释时间和费用。
- 无匹配时说明首个硬约束原因，并提供可执行的调整入口。
- 学生可体验校园邮箱、基本资料、授课设置和模拟审核的四步入驻流程；完成后资料会加入本机匹配池。
- 24 小时邀请占用、1 小时付费试课、72 小时双方确认。
- 学生接受后先记录试课时间、方式、地点和费用快照，再进入模拟付款。
- 成功后按基础时薪生成双方服务费，通勤补贴不参与计费。
- 学生工作台展示预计周收入、接单状态和固定时间占用。
- 本机保存体验进度，并提供超时演示和数据重置。
- 手机端采用三步需求填写、固定底部导航和老师资料底部弹层；已检查 320px 与 390px 宽度。

## 运行浏览器版

```powershell
npm install
npm run dev:h5
```

打开命令行显示的本地地址。已构建的静态文件位于 `dist/build/h5/`。

## 运行微信小程序版

```powershell
npm install
npm run build:mp-weixin
```

在微信开发者工具中导入 `dist/build/mp-weixin/`。真实发布前需在 `src/manifest.json` 填写小程序 AppID，并接入真实登录、服务端、校园邮箱、地图和支付。

## 验证

```powershell
npm test
npm run build:h5
npm run build:mp-weixin
```

测试覆盖通勤价格、预算交集、完整课次、多科目、无匹配诊断、学生入驻、试课安排、24 小时占用、72 小时确认、重复收费防护和成功后的时间占用。
